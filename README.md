# Journal Revenue Summarizer

Aplikasi Streamlit untuk menjumlahkan laporan PDF *Journal by Cashier and Transaction Code* per kategori revenue.

## Jalankan lokal
```
pip install -r requirements.txt
streamlit run app.py
```

## Deploy ke Streamlit Community Cloud
1. Push folder ini ke repo GitHub (`app.py`, `requirements.txt`).
2. Buka https://share.streamlit.io -> New app -> pilih repo & branch -> Main file: `app.py`.
